## TR
### kimim ben
Merhaba, ben retake. Bu blog Siber Güvenlik, Gizlilik, Teknoloji ve Genel fikirlerimin bulunduğu bir blog.

### içerik
Blog'da genellikle siber güvenlik, homelab projeleri, gizlilik (privacy) konuları ve CTF writeup'ları gibi içerikler bulabilirsiniz. Reverse engineering ile ilgili küçük çaplı projeler ve öğrenme sürecimdeki deneyimlerim, gizlilik konusundaki fikirlerim de burada yer alacak.

### altyapı
Bu blog, [Hugo](https://gohugo.io/) ile oluşturuldu ve [Terminal](https://github.com/ysfsvm/hugo-theme-retake-sh) temasının modifiye edilmiş bir versiyonunu kullayor ilgili temaya linkten ulaşabilirsiniz. Altyapı şu şekilde çalışı

- **Hosting**: Debian Linux tabanlı VDS
- **Web Server**: Nginx + Let's Encrypt
- **Reverse Proxy**: Cloudflare
- **Version Control**: Git + GitHub
- **Build System**: Hugo + GitHub Actions
